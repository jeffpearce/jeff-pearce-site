I build native macOS and iOS tools with a focus on clarity, reliability, and craftsmanship. These apps reflect the kind of software I enjoy creating: focused, purposeful, and designed to feel at home on Apple platforms.

### Help Architect

Help Architect is a modern, native macOS tool for creating professional help documentation. It provides a clean, structured workflow without the overhead of large documentation systems. Features include rich text editing, hierarchical topics, automatic indexing, and export to Apple Help Book format — all built with Swift and SwiftUI. It’s the successor to Help Crafter, redesigned from the ground up for today’s macOS.

Help Architect is currently in development. I’ll be looking for beta testers soon — if you’re interested, you can sign up to be notified when it’s ready.

### Help Crafter

Help Crafter is a long-standing macOS help authoring tool trusted by indie developers and small teams. It offers a simple, reliable way to build Apple Help Books without hand-crafting HTML or plist files. While Help Architect is the future of the platform, Help Crafter remains fully supported for users who prefer its classic workflow.

### QSOmate

QSOmate is a lightweight, native iOS logging app for amateur radio operators. It focuses on speed, clarity, and ease of use — letting you log contacts quickly whether you’re operating portable, mobile, or at home. QSOmate supports callsign lookup, band/mode tracking, and clean export options, all in a simple interface designed for real-world operating conditions.
